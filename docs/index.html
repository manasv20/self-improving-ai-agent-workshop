ParcelCo Flywheel — Workshop 1Doc 00 · Overview

The self-improving
support agent, one loop.

A frozen local LLM (Qwen) answers ParcelCo tickets inside one realtime loop. A Python checklist grades replies. If a reply fails, the same loop retries (heal). Across many tickets, reflect writes lessons and a gate keeps them only when scores improve. ParcelCo is fictional — the product is the visible loop, plus proof.

“One loop. Act, check, heal, reflect, keep only when the numbers say so. Weights stay frozen.” — The punchline

The split that proves it

PART ALearn set — 700 tickets
Tickets we learn from. Reflect mines its failures; the gate measures lift here.
PART BHoldout — 300 tickets
Score only. Proves we didn’t memorize. Live demo suite: core 35 (20A / 15B).

What we are not doing

✗ Not fine-tuning

Qwen weights stay frozen — training an SLM is Workshop 2.

✗ Not two systems

Heal vs improve are not separate loops — one loop, different steps.

✗ Not LLM self-grading

A hard Python checklist is the gate — the model never grades itself.

02Live Demo / Pre-Sales Path

“We don’t just call an LLM — we run a visible harness: LangChain for tools/model I/O, LangGraph for the loop, a hard checklist evaluator, LangFuse for traces, then an outer improve loop that only keeps changes that raise scores.” — The story in one line
Step 1 · Warm-up
60–90 s

Demo one ticket

  1. Open http://127.0.0.1:5050
  2. Click Demo one ticket
  3. Point at the strip as it lights: Click → LangChain → LangGraph → Evaluator (+ LangFuse if keys set)
  4. Open inspector: draft, ACTION: line, pass/fail
“Customer asks for a refund. LangChain pulls policy. Qwen drafts. Checklist grades — not the model grading itself. If it fails, LangGraph heals and retries.”
Step 2 · Baseline
3–6 min

Run baseline live: demo suite · 20A/15B

  1. Click Run baseline
  2. When done, read Part A and Part B rates — then point at Where it was
“Cold harness on a labeled suite. Holdout exists so we can’t fake improvement by memorizing the train tickets. Full catalog is 1000 tickets; we can run the core 35 live.”

Proof recording / overnight run: PARCELCO_SUITE=full (700A / 300B). Longer on full.

Step 3 · Improve loop
5–8 min

Start improve loop

  1. Set rounds to 2
  2. Click Start improve loop
  3. When Improve lights and history shows kept / reverted, pause on Where it is + Lift
“Outer loop writes lessons, re-scores. We only keep if Part A rises and Part B doesn’t collapse. That’s the flywheel you’d put in production governance — before vs after, not vibes.”
Step 4 · Traces
optional

LangFuse tab if configured

  1. Open the LangFuse project
  2. Find the latest trace for a generate call
  3. Show nested spans: retrieve context → LLM → score
“Observability is first-class — every sales engineer / risk reviewer can audit.”

If keys are empty: “Tracing hooks are wired; we turn them on with keys — strip shows optional/off.”

What not to claim

✗ Model weights

Don’t say the model weights improved — say the harness / memory / prompt improved.

✗ Hide latency

Don’t hide slow local 4B latency — frame it as “runs on your VPC / laptop.”

✗ Workshop 2

Training an SLM is a follow-on, not this demo.

06LangFuse — Self-Hosted with Docker

Langfuse is MIT open source. The workshop vendors the official compose stack under docker/langfuse/.

Start

# From the checkout containing pyproject.toml.
chmod +x scripts/start-langfuse.sh scripts/stop-langfuse.sh
./scripts/start-langfuse.sh

Or directly:

cd docker/langfuse
docker compose --env-file .env up -d
Table 4 — endpoints & credentials
WhatValue
LangFuse UIhttp://localhost:3000
Loginworkshop@parcelco.local / WorkshopDemo1!
Ports3000 UI · 9090 minio · localhost-only DB ports

Wire ParcelCo — repo root .env

LANGFUSE_PUBLIC_KEY=pk-lf-workshop-aa8504fbeda3a221cb5d6a06dd9bd83c
LANGFUSE_SECRET_KEY=sk-lf-workshop-4bfad518fa4844a0a79e1d3cd0585409
LANGFUSE_HOST=http://localhost:3000

Then restart the Flask app:

source .venv/bin/activate
python -m parcelco.cli serve

On the dashboard

  • Stack step LangFuse shows connected / Tracing ON when keys + auth work
  • LangFuse traces panel lists recent ticket traces with Open trace links
  • Open LangFuse opens the UI; the inspector links to that run’s trace

Langfuse sets X-Frame-Options: SAMEORIGIN, so the full UI opens in a tab rather than an iframe.

Stop

./scripts/stop-langfuse.sh

Notes

  • Needs Docker Desktop (or Docker Engine + Compose v2)
  • First boot pulls several images (web, worker, postgres, clickhouse, redis, minio) — can take a few minutes
  • Workshop secrets in docker/langfuse/.env are fine for local demos; rotate before any shared/networked deploy
